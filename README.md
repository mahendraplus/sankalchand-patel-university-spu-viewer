# 🔐 Sankalchand Patel University (SPU) - Student Data Breach Viewer 2025  
**Secure Profile Viewer for Sankalchand Patel University (SPU) **

Welcome to the official repository for the **SPU Student Data Breach Viewer**, an educational and ethical web application designed to simulate real-world data breach scenarios from **Sankalchand Patel University (SPU)**, North Gujarat's premier private university.

> ⚠️ This project is intended **strictly for educational and ethical hacking demonstrations**. All data is mock or anonymized for privacy protection.

---

## 🚀 Features

- 🔒 **PIN + Encryption Key Access**  
  Only users with a valid PIN and encryption key can unlock student profiles.

- 📊 **Student Data Breach Simulation (2025)**  
  Displays exposed data in a secure, controlled environment for academic awareness.

- 🧑‍💻 **Frontend + Backend Ready**  
  Easily integrate with Node.js or any API that handles student data securely.

- 🏫 **Built for SPU (Sankalchand Patel University)**  
  Reflects a real-world breach simulator using SPU student structure.
